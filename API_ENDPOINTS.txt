🔐 AUTHENTICATION (User)
═══════════════════════════════════════════════════════════════

1. User Login
   POST /api/auth/login
   Body: {
     "cardNumber": "1234567890123456",
     "pin": "1234"
   }

2. User Register
   POST /api/auth/register
   Body: {
     "cardNumber": "1234567890123456",
     "pin": "1234",
     "name": "Test User",
     "email": "test@example.com",
     "phone": "01712345678",
     "accountNumber": "1234567890"
   }

3. Get Profile (Protected)
   GET /api/auth/profile
   Headers: Authorization: Bearer YOUR_TOKEN

4. Update Profile (Protected)
   PUT /api/auth/profile
   Headers: Authorization: Bearer YOUR_TOKEN
   Body: {
     "name": "Updated Name",
     "email": "new@example.com",
     "phone": "01712345678"
   }

5. Change PIN (Protected)
   POST /api/auth/change-pin
   Headers: Authorization: Bearer YOUR_TOKEN
   Body: {
     "oldPin": "1234",
     "newPin": "5678"
   }

🔑 FORGOT PIN (3 Steps)
═══════════════════════════════════════════════════════════════

Step 1: Send OTP to Email
   POST /api/auth/forgot-pin
   Body: {
     "email": "test@example.com"
   }
   Response: {
     "success": true,
     "message": "OTP sent to te***@example.com",
     "email": "te***@example.com"
   }

Step 2: Verify OTP
   POST /api/auth/verify-otp
   Body: {
     "email": "test@example.com",
     "otp": "123456"
   }
   Response: {
     "success": true,
     "message": "OTP verified successfully",
     "resetToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
   }

Step 3: Reset PIN
   POST /api/auth/reset-pin
   Body: {
     "resetToken": "TOKEN_FROM_STEP_2",
     "newPin": "1234",
     "confirmPin": "1234"
   }
   Response: {
     "success": true,
     "message": "PIN reset successfully!"
   }

📝 NOTES
═══════════════════════════════════════════════════════════════

1. Protected routes require Authorization header:
   Authorization: Bearer YOUR_TOKEN_HERE

2. Get token from login/register response

3. Token expires in 3650 days (10 years)

4. All POST/PUT requests need Content-Type header:
   Content-Type: application/json

5. Response format:
   {
     "success": true/false,
     "message": "...",
     "data": {...}
   }
